# 算法说明

键级判定流程按顺序执行以下七个步骤。输入为一个仅有三维坐标的 `Struc` 对象，输出为带有正确键级信息的 RDKit `Mol` 对象。

## 步骤 0：初始键连矩阵

根据原子间距离和元素对截断半径表 `COMBINE2CUTOFF` 建立原子间的初始连接关系。

截断半径表以元素对原子序数的乘积乘以原子序数和作为键值索引：

```
键值 = ele_i × ele_j × (ele_i + ele_j)
```

例如 C 和 O：`6 × 8 × (6 + 8) = 672`，对应的距离-键级映射为：

```
672: ((1.15, 3), (1.30, 2), (1.55, 1))  ← 距离 1.15Å 以内三键、1.30Å 以内双键、1.55Å 以内单键
```

对于未在截断表中的元素对，以共价半径之和 × 1.2 为阈值建立单键连接。超出所有截断距离的原子对不建立连接。

此步完成后，再用 `MAX_BOND_NUMBER` 表（各元素最大连接数）裁剪每个原子上过多的连接。

## 步骤 1：初步多重键尝试

函数：`gen_multiple_bond`

- **第一次、第二次遍历**：仅对 N、O 原子（`ele > 6`）操作。若当前原子有剩余化合价，在邻接原子中找到同样有剩余化合价的，将对应单键升级一级
- **第三次、第四次遍历**：对 C 原子（`ele == 6`）同样处理

若此步后所有涉及元素的化合价均已满足（`remain_valence` 为 0），直接输出当前结果。

## 步骤 2：生成最小生成树

函数：`generate_spanning_tree`

以原子间欧几里得距离为边权重，使用 Kruskal 算法生成最小生成树。此步打破所有环结构，获得无环的基础连接骨架。生成树保证所有原子连通但无闭环。

## 步骤 3：大环闭合

函数：`find_rings（DFS 深度优先搜索）`

在**原始连接关系**（步骤 0 的结果）中查找 5、6、7 元环。对于找到的环，若环上相邻原子均有剩余化合价，则在当前位置添加单键，然后立即跳到下一个环。

## 步骤 4：小环闭合

同上，查找 3、4 元环并闭合。小环的判定门槛更低（不检查环内原子对距离），适用于三元环等张力较大的结构。

## 步骤 5：多重键补全

函数：`gen_multiple_bond_once`

不再区分 N/O/C 优先级，所有有剩余化合价的原子统一尝试将单键升级为多重键（遍历两次）。这一步骤在环结构已确定后进行，避免环的干扰。

## 步骤 6：电子修正

函数：`modify_electron`，按优先级处理三种情况：

### 6.1 形式电荷修正

原子 `remain_valence == 2`：

- 检查邻接原子中是否有化合价已满（`remain_valence == 0`）的 N 或 O：
  - **有** → 在两者之间额外成键，给予 O/N 正电荷、中心原子负电荷，返回 `"_e"`
  - **无** → 判定为**卡宾**（双自由基），直接将 `remain_valence` 置零并标记 `is_carbene = True`，返回 `"_cb"`

### 6.2 共轭体系修正

原子 `remain_valence == 1`（自由基）：

1. 收集所有 `remain_valence == 1` 的原子（共轭对成员）
2. 生成所有可能的自由基两两配对组合
3. 对每种配对，DFS 查找两原子间的路径。合法路径要求中间原子为化合价已满的 N/O，或形成共轭对
4. 若某配对方案的所有原子对都找到合法路径，则应用该方案：沿路径分配交替的单键/双键
5. 调整沿途原子的形式电荷以补偿化合价变化，返回 `"_cs"`

## 最终验证

统计主族元素（H, C, N, O, P, Cl, Br, Pd）的剩余化合价总和。若 > 0，判定失败；否则将 Struc 转换为 RDKit Mol 对象，返回状态和结果。

## 调试可视化

CLI 指定 `-d` 参数后，每一步的键连矩阵状态将保存为 PNG：

```
debug_vis/
├── name_1.png   # 步骤 0：初始距离键连
├── name_2.png   # 步骤 1：初步多重键
├── name_3.png   # 步骤 2：生成树（无环骨架）
├── name_4.png   # 步骤 3：大环闭合（5/6/7 元环）
├── name_5.png   # 步骤 4：小环闭合（3/4 元环）
├── name_6.png   # 步骤 5：多重键补全
└── name_7.png   # 步骤 6：电子修正
```

图中颜色含义：
- 灰色边 = 单键
- 蓝色边 = 双键
- 红色边 = 三键
- 节点标签 = 元素符号 + 原子序号
